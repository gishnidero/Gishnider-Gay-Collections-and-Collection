# Collections-and-Collection

The goal of this program is to showcase the utilization of Java collections, the Collection interface, and various methods within the Collections class. The program has the user enter 8 different words and, later in the program, enter one word to search for within said program. Note: If the user types the same word more than once, the program will have them try again to type a unique word, and if the word is not listed, it will notify them that the word in question is not listed and move on. But if properly entered, the program will print the following: the list itself, the size of said list, the longest and shortest word, a shuffled variant of the list, an index location of the word that was searched for, a rotated variant of the list, a reversed variant, an array output, and a list output.
Note: Due to formatting via the for-loop, the array output format will not look that much different from the list output.
