# Collections-and-Collection

The goal of this program is to showcase the utilization of Java collections, the Collection interface, and various methods within the Collections class. The program has the user enter 8 different words and, later in the program, enter one word to search for within said program. Note: If the user types the same word more than once, the program will prompt them to try again with a unique word, and if the word is not listed, it will notify them and move on. But if properly entered, the program will print the following: the list itself, the size of said list, the longest and shortest word, a shuffled variant of the list, an index location of the word that was searched for, a rotated variant of the list, a reversed variant, an array output, and a list output.
Some of the concepts and tools used were the List interface and ArrayList class, which were used to store the words used by the user. Along with several methods from the Collections class to manipulate the list: sort(), shuffle(), rotate(), reverse(), max(), and min(), just to name a portion of what is applied.
Note: Due to formatting via the for-loop, the array output format will not look that much different from the list output.
